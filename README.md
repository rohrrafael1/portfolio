## Running Locally

Use Node.js 20.9 or newer. Run `npm run lint`, `npx tsc --noEmit`, and
`npm run build` to validate changes. `npm start` serves the production build.

## Content

- Profile and contact information: `src/data/profile.ts`
- Case studies, including the Head TA page: `src/data/projects.ts`
- Medal categories and years: `src/data/awards.ts`, transcribed from `public/resume.pdf`
- Standalone projects: `public/games/formula-i` and `public/experiments/maedim`

The site presents a professional profile without recruiting availability text.
Itaú, StoneCo, and the Head TA role are featured on the homepage. Existing case
study URLs are preserved. Maedim appears at the bottom of the homepage and each
case study, with its original source repository linked alongside the local demo.
See its `PROVENANCE.md` for the source revision and packaging repairs. Static
legacy projects are excluded from the TypeScript application's lint rules.

Clone the repository:

```bash
git clone https://github.com/rohrrafael1/portfolio.git
```

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
