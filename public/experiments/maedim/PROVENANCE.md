# Maedim

Original project: https://github.com/rohrrafael1/Maedim

This is Rafael Rohr's existing Portuguese-language Mars education website,
included here so the portfolio's Visit site link has a working destination.
Source commit: bbffb2ab5d23e464f6747ae8eee79b0eac5ca8bf.

The original content, images, games, and simulations are preserved. Packaging
repairs remove obsolete root-relative stylesheet links (Bootstrap is already
loaded from its original CDN), use the existing background image instead of a
missing sky image, and point the map link at the included map image. External
embeds and CDN-hosted dependencies require internet access.
